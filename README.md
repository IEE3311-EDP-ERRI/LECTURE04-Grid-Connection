# LECTURE04-Grid-Connection
This material helps us to unsderstand how to obtain phase and frecuency of a measured waveform. The measure waveform is typically a single-phase or three-phase system which can be unbalance and can contain harmonic content. We wish to obtain clean phase and frequency stimation even under this conditions. 

The main goal of this lecture is that stundents understand how to track the phase and frequency of a single-phase and three-phase systems. <br>
